# eCommerce-dataset-samples

E-commerce dataset samples featuring thousands of records in total. All datasets were extracted using the **Bright Data API**.

## Some of the data points include:

    ┌─name──────────┬─type───────────┐
 1. │ id            │ UInt64         │
 2. │ date          │ Date           │
 3. │ product_id    │ String         │
 4. │ product_name  │ String         │
 5. │ category      │ String         │
 6. │ brand         │ String         │
 7. │ customer_id   │ String         │
 8. │ customer_name │ String         │
 9. │ gender        │ String         │
10. │ region        │ String         │
11. │ store_id      │ String         │
12. │ store_name    │ String         │
13. │ store_city    │ String         │
14. │ quantity      │ Int32          │
15. │ unit_price    │ Decimal(12, 2) │
16. │ discount      │ Decimal(5, 2)  │
17. │ sales_amount  │ Decimal(12, 2) │
18. │ profit        │ Decimal(12, 2) │
    └───────────────┴────────────────┘
